# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security problems.

Report them privately using GitHub's **Report a vulnerability** button on the **Security** tab of this repository, or email **contact@cyberops.team**.

Include what you found, how to reproduce it, and the version or commit affected. We'll acknowledge your report within 5 working days and keep you updated until it's resolved.

## Supported versions

Only the latest version on the `main` branch receives security fixes.
